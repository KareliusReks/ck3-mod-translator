# CK3 Mod Translator

Программа для Windows, которая сама находит в модах Crusader Kings III текст без перевода, переводит его машинным переводчиком и кладёт перевод внутрь каждого мода.

Это отдельная программа, а не мод из Steam Workshop: сам мод CK3 не может читать чужие файлы и выходить в интернет.

## Как пользоваться

1. Скачайте `release/CK3ModTranslator.exe` и положите в отдельную папку (рядом появятся файлы настроек и кэша).
2. Запустите. Проверьте три пути: папка модов в «Документах», папка Steam Workshop (`...\steamapps\workshop\content\1158310`) и папка игры (`...\Crusader Kings III\game`).
3. Выберите языки «С языка» и «на язык» и переводчик.
4. Нажмите «Только отчёт», чтобы увидеть, сколько строк не переведено, или «Перевести».
5. Запустите игру. После обновления модов нажмите «Перевести» ещё раз: уже переведённое берётся из кэша.

Кнопка «Удалить перевод» убирает всё, что создала программа. Кнопка «Отмена» останавливает идущий перевод: уже переведённое сохраняется и записывается в моды, продолжить можно повторным нажатием «Перевести».

## Что делает программа

- Берёт моды из текущего плейсета (или все моды, если снять галочку).
- Находит ключи, у которых есть текст на исходном языке, но нет на языке перевода ни в игре, ни в модах.
- Для решений, взаимодействий и черт вообще без текста создаёт ключ из имени (только при переводе с английского).
- Прячет от переводчика игровую разметку (`[...]`, `$...$`, `#X ... #!`, значки, `\n`) и возвращает её на место. Если разметка повреждена, строка переводится по кускам или остаётся как была.
- По галочке «Считать непереведённым текст, который совпадает с исходным» находит моды, где в папке перевода лежит тот же английский текст.
- Переводит в несколько потоков сразу (поле «Потоков», от 1 до 16). Для `google_free` всегда один поток, иначе Google блокирует. При временных отказах сервиса запрос повторяется с паузой.
- Пишет в каждый мод один файл `localization/<язык>/replace/zz_autoperevod_l_<язык>.yml`. Чужие файлы не меняются, а папка `replace` позволяет нашим строкам заменить одноимённые строки мода.
- Хранит переводы в `cache.json` (для других пар языков `cache_<из>_<в>.json`).

## Переводчики

| Название | Что нужно |
|---|---|
| `google_free` | ничего; при большом объёме Google может временно отказать, тогда запустите позже |
| `google_cloud` | ключ Google Cloud Translation |
| `deepl` | ключ DeepL API |
| `openrouter` | ключ OpenRouter и название модели |
| `silkcompute` | ключ SilkCompute и название модели |
| `custom` | любой сервис с API в формате OpenAI: `custom_base`, `custom_key`, `custom_model` в `config.json` |

Ключи хранятся только в `config.json` рядом с программой. Не выкладывайте этот файл.

## Настройки

- Кнопка «Моды...»: список найденных модов с галочками. Отметьте те, которые нужно перевести. Если не отмечен ни один, переводятся все. Отмеченный мод переводится, даже если его нет в текущем плейсете.
- Кнопка «Исключения...»: ключи, которые не надо переводить. Каждое исключение включается и выключается галочкой, новые добавляются в том же окне. Исключение — регулярное выражение по имени ключа, например `^abc_` для ключей, которые начинаются на `abc_`. Исключения хранятся в `config.json`; строки из старого `skip.txt` переносятся туда при первом запуске.
- `config.json`, `skip_mods`: части названий модов, которые не надо трогать.
- Папка `translations`: свои файлы локализации с ручным переводом, они важнее машинного.
- Поле «Пожелания к стилю» передаётся нейросети.

Командная строка: `--run` (перевести без окна), `--dry` (только отчёт), `--clean` (удалить перевод).

## Важно

- Перевод машинный: возможны ошибки, падежи у ссылок на игровые понятия не согласуются.
- Steam при обновлении мода может стереть файл перевода, тогда запустите программу снова.
- Программа собрана PyInstaller, некоторые антивирусы ругаются на такие файлы. Исходный код лежит здесь же: `ck3_perevodchik.py` (нужен Python 3.10+ без дополнительных библиотек).
- Что и какие моды переводить, решает пользователь, и отвечает за это он сам. Текст модов отправляется выбранному сервису перевода.
